# Invade

**Play. Walk. Conquer.** Friends form two teams. Every step you take today (straight from Apple Health) becomes soldiers your team uses to take a shared map.

Hackathon project: Lytvyn.AI.Foundation AI Hackathon, Barcelona, Oct 2026.

## Quick start

```bash
gh repo clone emiraksay/invade && cd invade
npm install
# put the .env.local you received privately at apps/web/.env.local (see .env.example)
npm run dev        # http://localhost:5173
npm test && npm run typecheck && npm run lint   # before every PR
```
